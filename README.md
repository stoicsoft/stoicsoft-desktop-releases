# StoicSoft

**One app to install, update, open and remove every StoicSoft app, on Mac and Windows.**

StoicSoft keeps all your StoicSoft apps in one window: see which have
updates and install them in one click, check your licence keys, compare
bundles, post feedback and join the community chat.

- **Safe updates.** Every download is checked against the app's own
  signature before it replaces anything, and a running app is never
  replaced without asking.
- **Feedback from your AI tool.** Claude Code, Codex, Cursor and other MCP
  clients can report bugs with screenshots and request features as you.

## Download

Get the newest version from [stoicsoft.com/desktop](https://stoicsoft.com/desktop) or
[Releases](https://github.com/stoicsoft/stoicsoft-desktop-releases/releases/latest):

- **Mac:** the `.dmg` for your Mac (`aarch64` for Apple silicon, `x64` for Intel). macOS 12 or later.
- **Windows:** `x64-setup.exe`, or `arm64-setup.exe` on an Arm PC; the `.msi` is for managed installs.
  Windows 10 or 11. The installer isn't code-signed yet, so SmartScreen may warn the first time:
  choose More info, then Run anyway.

Once installed, StoicSoft updates itself.

This repository holds the signed releases and the update feed only.
Report bugs and request features at [feedback.stoicsoft.com](https://feedback.stoicsoft.com).
